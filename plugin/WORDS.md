# Words

The plugin uses the OATS Desktop's words for every act, state, label, notice and refusal (the UX
standard, section 2). This file holds each place where bb's nature, or the plugin's, changes a word:
what the Desktop says, what the plugin says, and why. Nothing else is reworded.

The tables the plugin copies from the Desktop whole are named in the header of the file that holds
them: `app/ui/text.ts` (the display filter; its functions are in `model/text.ts`), `app/ui/words.ts` (the needs-input words and times, an
instance's name as words).

| Thing | The Desktop says | The plugin says | Why |
|---|---|---|---|
| The state of an agent, as a word beside its mark | no word: the dot alone, named "running", "stopped" or "status unknown" for a screen reader | **Working**, **Idle**, **Needs you**, **Stopped**, **Failed**, **Unreachable**, each beside its mark; and **Running outside OATS**, for an agent OATS recorded stopped whose harness the kernel reports running ("Outside OATS", below). That is the whole set: what follows a state is its reason. | The standard: a state is always a mark and its word. bb's kernel rows say more than running or not: a session that fell back to a shell (Failed) and one the kernel cannot reach (Unreachable). |
| The accessible name of a state's mark that stands alone | "running", "stopped", "status unknown", "Needs input" | the same four; "failed" and "unreachable" for the two states the Desktop does not draw; "running outside OATS" | The Desktop's names where it has one. |
| An agent that is there and does not work | "status unknown" (a grey bullseye) | **Idle** (named "status unknown") | An agent that is there and at rest. For an agent on a bb thread that is what bb says of the thread (the row "Whether an agent on a bb thread says Working or Idle", below), never the kernel's `running`; for a tmux agent it is the kernel's own word. |
| Automations: the notice that the host scheduler is off | "The scheduler is not running on this computer, so nothing here runs until it is enabled." (one sentence in a banner) | title **The scheduler is not running on this computer**, then "Nothing here runs until it is enabled." | The standard's notice has a title: the sentence's first clause is the title, the rest follows. | Automations: a list that could not be read | the kernel's message alone, in the error colour | title **Schedules could not be read** (or **Triggers …**), the kernel's message under it, its code after, Retry | The standard: a person's words first, the kernel's code after. ### Since when, by state (the status line of a thread's row)

A time is said only where the kernel recorded one; the plugin invents none.

| State | The time said | The kernel's fact | Where |
|---|---|---|---|
| Needs you | "12 min" ("4 d"): how long, no clock time. Since when ("since 14:03") is with what it asks, in the instance panel | the claim's `since` (`oats status`: `waitingOnYou.since`). None when the question is bb's own: OATS recorded no claim. | every place; the clock time in the instance panel alone |
| Working | none on a line or a row. "Started 12 min ago" is a fact of the instance panel's Session | the row's `startedAt`: the last time OATS started it (a spawn, `session start`, `session restart`). A session bb resumed since (a lost session brought back by a message) keeps this time: the row cannot tell a resume, so the fact says what the field is, true before and after one. | the instance panel's Session |
| Stopped | none on a line or a row. The thread's row reads no events. |
| Idle | none | the kernel records none | |
| Failed | none; the reason in its place: "session ended" | the kernel records none (a session that died wrote nothing) | |
| Unreachable | none, and no reason: the state's word says it; the kernel's own message is under Details | the kernel records none | |

## Outside OATS: an agent that something happened to outside OATS

The Desktop has no such states: it runs the agent's session itself. The state's word comes first
and is one of the set (the first table: Needs you, Working, Idle, Stopped, Failed, Unreachable,
Running outside OATS); then the reason: two or three words, on the thread's line and on the
sidebar's row (a row is never three lines). A sentence stands in the reason's place only where a
person would otherwise do harm (a message that starts an agent outside OATS, a process that may
still run), and never names the remedy: that is the button beside it. Each rests on one
fact of the kernel's row and one answer of bb's (`app/outside/say.ts`, `words.ts`). A reason said
in the warning tone needs a remedy, or warns of a thing a person may do by mistake. No line says a
time: when OATS stopped an agent is a fact of the instance panel's Session. The
home lists an agent that runs outside OATS among those that need you ("The home", below): one
number in the sidebar's foot, the home's badge, its heading and its summary line.

| The state | The reason: what happened | The thread's line says, after the state | The sidebar's row says, after the state | The fact it rests on |
|---|---|---|---|---|
| **Stopped** | it was stopped, and not with the machine, and its thread is open | **A message here starts it outside OATS.**, in the warning tone, with Start. Where bb holds a question on that thread (the line then says "Needs you"): **Stopped. An answer here starts it outside OATS.** | nothing after the state | the row: `runtimeState: "stopped"`, and `sessionEnd` anything but "lost" ("stopped": an operator's stop; "exited"; none: a retire pending, a rollback incomplete, a spawn in progress): the warning fails closed. The roster draws it on its thread. bb's composer stays live under a stopped agent: a message there starts its harness again and OATS keeps saying "stopped". |
| **Stopped** | it stopped with the machine, and its thread is open | **with the machine. OATS starts it again when the machine is back.**, with Start | **with the machine** | the row: `runtimeState: "stopped"`, `sessionEnd: "lost"`; bb lists its thread. `oats host run` stops a home as the machine stops, and the kernel's sweep resumes a lost session. No warning: nothing is wrong, and a message that reaches it first starts an agent OATS sees running. |
| **Stopped** | it is stopped (its session not lost), and bb has its thread archived | **archived in bb**, with Start… and Retire… on the archived thread's own row (what Start does is its dialog's one line) | nothing after the state, in the plain tone (nothing is wrong: a provider that archives at stop leaves every stopped agent so); the row opens the archived thread | the row: `sessionEnd` not `lost`; bb: the thread of `session.threadId` has `archivedAt` set. Start makes a new thread; bb shows the archived one to read. |
| **Stopped**, in the warning tone | OATS lost its session, and bb has the thread archived | **Archived in bb while running: it may still run.**, with Stop and Retire | **archived in bb**, the mark in the warning tone | the row: `runtimeState: "stopped"`, `sessionEnd: "lost"`; bb: `archivedAt` set. bb's Archive never touches the harness: the process stays loaded until OATS stops it. "Stopped" is the kernel's word for the row; the warning and the sentence say what it does not. |
| its own state (**Idle**, **Needs you**), in the warning tone | its row still says it runs, and bb has the thread archived | on the archived thread's own row: **Archived in bb while running: it may still run.**, with Stop and Retire | **archived in bb**, the mark in the warning tone; the row opens the archived thread | the row: not stopped, failed or unreachable, and not `running: false`; bb: `archivedAt` set. Its state's word stays what the row says (bb lists no thread to read a turn from: "Idle"). |
| **Stopped**, in the warning tone | bb has no thread of its id (deleted in bb) | on the agent's own page, in the warning tone under the header's "Stopped": **deleted in bb**, with Start… and Retire… | **deleted in bb**, the mark in the warning tone | the row is stopped (an operator's stop, or a session OATS lost); bb has no thread of that id, active or archived. bb's Delete ends the harness. "its bb thread is gone" is said of no row of the sidebar. |
| **Idle** | no harness is loaded for it, and its thread is open | **not loaded**, with Start (its dialog says first that a message in the thread carries the conversation on) | **not loaded** | the row: `running: false`, `runtimeState: "unknown"`, no `sessionEnd` (the kernel's contract for a provider row whose session is there with no harness; printed by the bb provider from its next release). Not "Stopped", and no warning: a message carries the conversation on and OATS reads it running; Start would begin a new thread and leave this conversation behind. |
| **Running outside OATS**, in the warning tone | OATS recorded it stopped, and the kernel reports its harness running | **recorded stopped**; under the line a notice: **<Name> is running in bb, but OATS recorded it as stopped.** **Someone sent it a message in bb. know what an agent needs; what a person may want and does not need is behind a disclosure a finger
can reach; no sentence states the ordinary. Each sentence below was drawn before that direction and
is no longer; the reason of every row is that direction, and the last column says what carries
its meaning now. A row above that was shortened says its new words there, and keeps its reason.
