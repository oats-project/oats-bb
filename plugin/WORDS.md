# Words

The plugin uses the OATS Desktop's words for every act, state, label, notice and refusal (the UX
standard, section 2). This file holds each place where bb's nature, or the plugin's, changes a word:
what the Desktop says, what the plugin says, and why. Nothing else is reworded.

The tables the plugin copies from the Desktop whole are named in the header of the file that holds
them: `app/ui/text.ts` (the display filter; its functions are in `model/text.ts`), `app/ui/words.ts` (the needs-input words and times, an
instance's name as words).

| Thing | The Desktop says | The plugin says | Why |
|---|---|---|---|
| The state of an agent, as a word beside its mark | no word: the dot alone, named "running", "stopped" or "status unknown" for a screen reader | **Working**, **Idle**, **Needs you**, **Stopped**, **Failed**, **Unreachable**, each beside its mark; and **Running outside OATS**, for an agent OATS recorded stopped whose harness the kernel reports running ("Outside OATS", below). That is the whole set: what follows a state is its reason. | The standard: a state is always a mark and its word. bb's kernel rows say more than running or not: a session that fell back to a shell (Failed) and one the kernel cannot reach (Unreachable). |
| The accessible name of a state's mark that stands alone | "running", "stopped", "status unknown", "Needs input" | the same four; "failed" and "unreachable" for the two states the Desktop does not draw; "running outside OATS" | The Desktop's names where it has one. |
| An agent that is there and does not work | "status unknown" (a grey bullseye) | **Idle** (named "status unknown") | An agent that is there and at rest. For an agent on a bb thread that is what bb says of the thread (the row "Whether an agent on a bb thread says Working or Idle", below), never the kernel's `running`; for a tmux agent it is the kernel's own word. |
| Automations: the notice that the host scheduler is off | "The scheduler is not running on this computer, so nothing here runs until it is enabled." (one sentence in a banner) | title **The scheduler is not running on this computer**, then "Nothing here runs until it is enabled." | The standard's notice has a title: the sentence's first clause is the title, the rest follows. No word is changed. |
| Automations: the notice that this computer has no host name | "This computer has no host name, so it runs none of the workspace's schedules. Name it in this deployment's local settings to take on the ones assigned to it." | title **This computer has no host name**, then "It runs none of the workspace's schedules. Name it in this deployment's local settings to take on the ones assigned to it." | The same: a title, then the rest of the Desktop's sentence. |
| Automations: a list that could not be read | the kernel's message alone, in the error colour | title **Schedules could not be read** (or **Triggers …**), the kernel's message under it, its code after, Retry | The standard: a person's words first, the kernel's code after. The Desktop has no sentence of its own here. |
| Automations: a next run that is in the past | "Next 3 h ago": `Next ${next.label}` with its relative time, whatever the time is (`packages/desktop/renderer/views/automations.mjs:434`, and a row's page at `:591`) | the same, "Next 3 h ago" | Not a difference, written here so nobody takes it for a defect of the plugin. ## The roster: the sidebar, the thread's row, the confirmations

| Thing | The Desktop says | The plugin says | Why |
|---|---|---|---|
| The age of what is still shown | "just now", "45s ago", "3 min ago", "at 14:05" (`observedAgeText`) | always relative, one form: **less than a minute ago**, **12 min ago**, **3 h ago**, **2 d ago** (`readAge`, `app/ui/words.ts`) | The lead's ruling on the stale state: a read that could not be made again must not read as fresh, and one form of age on a screen. |

| The roster kept while OATS cannot be read | "Last observation — <age>" over the roster, "showing what was read <age>", actions held | ONE notice (`app/roster/unreadable.tsx`), with the age said once and in one form: **Showing what was read <age>.** | The Desktop's sentence; its second line with the same age is left out (one form of age, said once: the lead's ruling R4). |
| Acts on a roster that is the last one read | held | HELD too: Stop, Start, Restart, Retire and New agent stay in their place, off (the sidebar's New agent says its reason as words under it where the sidebar's notice is down to one line, beside a page's full notice: a phone has no hover, and the full notice names New agent itself). | The act on a thread's own line | the Desktop's row actions | **Stop** on a line that says Working or Idle (the plan first, then the confirmation); **Answer** on a Needs-you line of an agent that asked through OATS (it opens the instance panel and moves the focus to "Needs input"; what is asked is on the line); **Start**, **Restart**, **Retry** as before. No act on a question bb itself shows, and no Stop on a Needs-you line (the thread's menu has it). | One act per line: the one that applies to the state (B3). |
| An agent the kernel refuses as one it does not know (a stop plan or a retire plan refused with E_SESSION_UNKNOWN) | **Forget…** on a row its server no longer lists | the row says **Not in OATS any more** in its state's place until the next roster; the confirmation says "<name> is not in OATS any more", "Nothing was changed." Any other act on such an agent shows the kernel's refusal as it is. | bb has no server-side roster to forget from: the next read of `oats status`, made right after every act, drops the row. |
| An agent's name | the instance's name as words ("Oats expert maintainer lanes") | the same, everywhere the plugin draws an agent (`agentName`, `app/ui/words.ts`: the Desktop's `instance-display-name.mjs` through the display filter); bb's title for the thread is never the name | The lead's ruling R1. The provider titles the bb thread with the same words. |
| A name made of a version (`…-oats-0-69-4`) | every `-` is a space: "… oats 0 69 4" (`instanceDisplayName`) | the same: the Desktop's rule joins no digits, and the plugin's name is the Desktop's | One name everywhere; the real name is the row's title. |
| A roster row's lines | one line each, cut | at most THREE: the name on one or two lines, cut with "…" only after the second (the whole name is the row's title); the second block (state · soul · where it runs) on ONE line, where the SOUL gives way first (down to its "…"), never the state's word nor "tmux"; the long last phrase of a row whose thread is gone ("its bb thread is gone") gives way after the soul, and nothing is drawn past the row | Names of 21 to 43 characters are the rule in a real deployment: cut at one line, most of a roster reads the same (the lead's ruling on its images). |
| The thread row's facts | instance of, Parent, Owning human, Messaging ID (the instance panel's) | the same four labels, and **Children** | One vocabulary for one fact (R3); the team's id is not in a label. |
| The way to the instance panel, on a thread | (the panel is beside the roster) | the button **Instance panel** | It says what it opens. |
| When an agent's claim (what it waits on a person for) is shown | `waitingClaim`: shown unless the session is known stopped | ONE rule for bb and tmux (`claimOf`, `model/view.ts`): hidden only for an agent the kernel calls stopped (its word "stopped", or not running with no word); shown in every other case: running, nothing said of it, a harness that ended in a shell, a session that cannot be reached, no harness loaded | "A claim wins": a person must be told that an agent waits whenever anything of it may still be there; a stopped agent waits for nobody. (The spec's A2, amended 2026-11-23; before, a tmux row showed its claim only while the kernel said it ran.) |
| The thread's row, an agent that waits with no claim of the kernel's | (no such case: the Desktop has no session of its own) | **bb shows its question in this thread** | The question is bb's own pending interaction; the kernel recorded no claim. |
| Whether an agent on a bb thread says **Working** or **Idle** | the session's own activity (the Desktop runs the session) | bb's own status of the agent's thread, read by the bb session provider's own rule (`threadWorks`, `model/view.ts`; the rule of its release that scans the harness, in which a failed queued message is at rest): **Working** while a turn runs, starts or stops, or while the thread is at rest (idle, pending, or bb's failed turn) with a message bb will start by itself; **Idle** at rest with nothing in line, or with a queued message that bb marks failed. Such an agent may still turn Working by itself: bb shows "failed" over a message that waits when both are queued, and while it retries one | The kernel's `running` says that a harness is loaded, not that the agent works: a provider answers true for an idle agent. For a tmux agent the kernel's word is its own, and stays. A provider's agent whose thread bb does not list is **Idle**: its thread's status cannot be seen. |
| A thread whose last turn bb reports as failed (bb's status "error"), with nothing in line | no such case | **Idle** (nothing after it, in this release) | bb's last turn failed and bb shows that in the thread; the session is there, at rest. OATS's **Failed** is a session that ended, which this is not. |
| The thread's row, an agent whose session ended in a shell | "Its session ended" in the instance panel | **Failed** · **Its session ended**, with Restart | The Desktop's words; the state's word beside them is the plugin's (first table). |
| The thread's row, an agent the kernel cannot reach | the kernel's message | **Unreachable** · **OATS cannot reach its session**, with Retry; the kernel's message (often a URL or an error's code) under **Details**, after "OATS says:" | A person's words on the line; the kernel's text one press away (the standard, section 2). |
| A row of an agent with no bb thread | the row is the instance, whatever runs it | "<state> · <soul> · **tmux**"; for one whose thread bb has archived or deleted, what happened, in the soul's place ("Outside OATS", below). "its bb thread is gone" is said of no row of the sidebar (the home says it of an agent it cannot send to: "The home", below). The agent's own page says the sentence: "Runs in tmux on <machine>. Attach from a terminal:" with the command | In bb an agent is a thread; one without a thread is said to be so, and opens its own page. The row says one word, so that the second block of a tmux agent's row fits its one line (the row below: at most three lines). |
| Nobody waits | "Nothing needs you." | the same | none. |
| The act that makes an agent | **New agent** | the same, a button at the roster's foot | none. |
| The plugin's pages in the sidebar | one **Workspace** row (a page with tabs) | the heading **Workspace** over a row per page | bb's pages are routes, not tabs of one page; the Workspace page with its tabs is a later piece. |

### Since when, by state (the status line of a thread's row)

A time is said only where the kernel recorded one; the plugin invents none.

| State | The time said | The kernel's fact | Where |
|---|---|---|---|
| Needs you | "waiting 12 min (since 14:03)" | the claim's `since` (`oats status`: `waitingOnYou.since`). None when the question is bb's own: OATS recorded no claim. | every place |
| Working | "started 14:03" | the row's `startedAt`: the last time OATS started it (a spawn, `session start`, `session restart`). A session bb resumed since (a lost session brought back by a message) keeps this time: the row cannot tell a resume, so the line says what the field is, true before and after one (the turn it works on may be newer). | every place that draws the status line |
| Stopped | "since 14:03" | the time of the instance's last `stopped` event (`oats instance events`) | the open thread's row: one read for one agent, made again each time the agent is seen to turn stopped; an event older than the session's start is not this stop's, and no time is said. The sidebar's rows and the panel's header say no time. |
| Idle | none | the kernel records none | |
| Failed | none; the reason in its place: "Its session ended" | the kernel records none (a session that died wrote nothing) | |
| Unreachable | none; the reason in its place: "OATS cannot reach its session", with the kernel's own message under Details | the kernel records none | |

## Outside OATS: an agent that something happened to outside OATS

The Desktop has no such states: it runs the agent's session itself. The state's word comes first
and is one of the set (the first table: Needs you, Working, Idle, Stopped, Failed, Unreachable,
Running outside OATS); then the reason: one sentence with one remedy on the thread's line, and on
the sidebar's row a few words in the soul's place (a row is never three lines). Each rests on one
fact of the kernel's row and one answer of bb's (`app/outside/say.ts`, `words.ts`). A reason said
in the warning tone needs a remedy, or warns of a thing a person may do by mistake. The
home lists an agent that runs outside OATS among those that need you ("The home", below): one
number in the sidebar's foot, the home's badge, its heading and its summary line.

| The state | The reason: what happened | The thread's line says, after the state | The sidebar's row says, after the state | The fact it rests on |
|---|---|---|---|---|
| **Stopped** | it was stopped, and not with the machine, and its thread is open | since when · **A message sent here in bb starts it again without OATS. Use Start.**, in the warning tone, with Start. Where bb holds a question on that thread (the line then says "Needs you"): **OATS recorded it stopped. A message sent here in bb starts it again without OATS. Use Start.** | the soul | the row: `runtimeState: "stopped"`, and `sessionEnd` anything but "lost" ("stopped": an operator's stop; "exited"; none: a retire pending, a rollback incomplete, a spawn in progress): the warning fails closed. The roster draws it on its thread. bb's composer stays live under a stopped agent: a message there starts its harness again and OATS keeps saying "stopped". |
| **Stopped** | it stopped with the machine, and its thread is open | since when · **with the machine. OATS starts it again when the machine is back.**, with Start | **with the machine** | the row: `runtimeState: "stopped"`, `sessionEnd: "lost"`; bb lists its thread. `oats host run` stops a home as the machine stops, and the kernel's sweep resumes a lost session. No warning: nothing is wrong, and a message that reaches it first starts an agent OATS sees running. |
| **Stopped** | it is stopped (its session not lost), and bb has its thread archived | since when · **Its conversation is archived in bb. Start begins a new one.**, with Start… and Retire… on the archived thread's own row | the soul, in the plain tone (nothing is wrong: a provider that archives at stop leaves every stopped agent so); the row opens the archived thread | the row: `sessionEnd` not `lost`; bb: the thread of `session.threadId` has `archivedAt` set. Start makes a new thread; bb shows the archived one to read. |
| **Stopped**, in the warning tone | OATS lost its session, and bb has the thread archived | **Its conversation was archived in bb while it ran, and its process may still run. Stop it, then start it from OATS.**, with Stop and Retire | **archived in bb**, the mark in the warning tone | the row: `runtimeState: "stopped"`, `sessionEnd: "lost"`; bb: `archivedAt` set. bb's Archive never touches the harness: the process stays loaded until OATS stops it. "Stopped" is the kernel's word for the row; the warning and the sentence say what it does not. |
| its own state (**Idle**, **Needs you**), in the warning tone | its row still says it runs, and bb has the thread archived | on the archived thread's own row: **Its conversation was archived in bb while it ran, and its process may still run. Stop it, then start it from OATS.**, with Stop and Retire | **archived in bb**, the mark in the warning tone; the row opens the archived thread | the row: not stopped, failed or unreachable, and not `running: false`; bb: `archivedAt` set. A person archived the conversation of an agent whose process goes on: bb's Archive never touches the harness. Its state's word stays what the row says (bb lists no thread to read a turn from: "Idle"). |
| **Stopped**, in the warning tone | bb has no thread of its id (deleted in bb) | on the agent's own page, in the warning tone under the header's "Stopped": **Its conversation was deleted in bb. Start it from OATS for a new one.**, with Start… and Retire… | **deleted in bb**, the mark in the warning tone | the row is stopped (an operator's stop, or a session OATS lost); bb has no thread of that id, active or archived. bb's Delete ends the harness. "its bb thread is gone" is said of no row of the sidebar. |
| **Idle** | no harness is loaded for it, and its thread is open | **not loaded. To carry on, send it a message here. Start begins a new conversation.**, with Start | **not loaded** | the row: `running: false`, `runtimeState: "unknown"`, no `sessionEnd` (the kernel's contract for a provider row whose session is there with no harness; printed by the bb provider from its next release). Not "Stopped", and no warning: a message carries the conversation on and OATS reads it running; Start would begin a new thread and leave this conversation behind. |
| **Running outside OATS**, in the warning tone | OATS recorded it stopped, and the kernel reports its harness running | **recorded stopped** since when; under the line a notice: **<Name> is running in bb, but OATS recorded it as stopped.** **Someone sent it a message in bb. Stop it, or start it from OATS so that OATS tracks it again.** Stop: **stops the harness that runs outside OATS**. Start: **starts it from OATS, in a new conversation**. The kernel's own sentence (for example "a harness runs in dev-a on bb, and OATS recorded this instance stopped: stop it with `oats instance stop dev-a`, or start it from OATS") and its code `running-outside-oats` are under Details. | nothing: the state fills the row's line. The agent is counted in "N need you". | the row's `outsideOats`, where the kernel lists `provider-outside-oats`. One statement about the agent: never "Stopped" beside a notice that says it runs. A person's words on screen; no command where the two buttons do the same. |
| **Failed** | its session ended, on an open thread | **Its session ended. Restart it, or send a message here.**, with Restart | the soul | the row: `runtimeState: "shell"`; the thread is open. A message in bb's composer starts it again and the next status read sees it running: no warning. "Its session ended" is the Desktop's. |
| any | a row the tree draws on no thread, with no reason above | (no thread to draw a line on) | where its thread is: **archived in bb**, **deleted in bb**, **no bb thread**, **thread not shown in bb** (hidden in bb, or another row's) | bb's answer alone. The soul until bb has answered. |
